Blood and donor management system

The Blood and Donor Management System is a desktop CRUD application developed in C# using Windows Forms (.NET) to streamline blood request handling and donor coordination. It features a navigation sidebar with "Request" and "History" options, a central displaying active requests with details like blood group, quantity, location, reason, date, and status and an entry form utilizing controls to input requirements. Users can create new entries via the "New" and "Save" buttons, access a registered "Donor List" or sign up via "Want To Donate" to fulfill pending requests.

C#, MySQL, Visual Studio

Bus Ticket Management System

The Bus Ticket Management System is a user-friendly application that allows passengers to search for available buses and book tickets conveniently. Users can select their departure and destination, choose a departure date, specify the number of passengers, and select the bus and seating types. The system also provides options for one-way and round-trip journeys, along with features to cancel and print tickets. It simplifies the ticket booking process and helps manage bus reservations efficiently.

C#, MySQL, Visual Studio

My Calculator

This project is a standard desktop graphical calculator application titled "MY CALCULATOR", built using Java Swing. It features a top display screen and the interface includes a full numeric keypad, basic arithmetic operators, utility controls, like CE (Clear Entry) and back (Backspace), as well as input modifiers for percentage. The application uses Java's ActionListener event-handling model to listen for button clicks, parse user input strings, execute arithmetic operations, and dynamically update the display screen with the results.

Java, Java Swing (GUI), Layout Managers and Event Handling.
